Este painel é um radar de desk research para acompanhamento interno da pesquisa — não é uma fonte citável por si mesma. Itens incluídos apenas quando localizados com link real via busca; nenhum item é inventado para preencher categorias ou semanas. As abas "Clima político" e "Resumo" são sínteses escritas a partir dos itens coletados, revisadas a cada atualização; "Nuvem de palavras" e "Atores" são calculadas automaticamente a partir dos textos e das entidades marcadas em cada item.
